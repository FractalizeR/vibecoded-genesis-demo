## Troubleshooting

### Частицы не видны

1. Проверить `timeline.isParticlesVisible()` — должно быть `true` после t=4s
2. Проверить, что material имеет `transparent: true`
3. Проверить, что частицы добавлены в scene: `scene.children`

### Шейдер не компилируется

1. Открыть консоль браузера
2. Найти ошибку GLSL
3. Типичные проблемы:
   - Отсутствует `;` в конце строки
   - Неправильный тип переменной
   - Неопределённая переменная/функция

### Низкий FPS

1. Уменьшить `config.PARTICLES.count` до 100000
2. Уменьшить `config.DUST.count` до 2000
3. Уменьшить `config.BLOOM.strength` до 1.0
4. Проверить, что нет утечек памяти (создание объектов в game loop)

### ES modules не загружаются

```
Access to script at 'file://...' from origin 'null' has been blocked by CORS policy
```

**Решение:** Запустить через HTTP сервер:
```bash
npx serve .
```
